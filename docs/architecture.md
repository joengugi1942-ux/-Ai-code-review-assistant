## Architecture

**Lapo** - FastAPI-powered AI Code Review Assistant

- **FastAPI** application in `app/main.py`
- **Core config and security** in `app/core/`
- **HTTP API** in `app/api/v1/`
- **Domain logic and integrations** in `app/services/`
- **LLM interaction** in `app/ai/`
- **Pipelines** in `app/pipelines/`
- **Utilities** in `app/utils/`
